# Lockstep version targets — the single list of every place the product
# version is written down. One target per line:
#   <files><TAB><ERE pattern>[<TAB><allowed suffixes>]
# <files> is a space-separated list of paths or globs; the pattern uses
# __V__ where the version appears; the optional third column lists literal
# suffixes that may follow the version in that slot (space-separated).
# version-bump.sh rewrites the version inside each pattern; version-check.sh
# fails if any occurrence is not exactly the version (plus an allowed
# suffix) from quarry/types/version.go, or if a target matches nothing.
#
# Anything that prints the version and is not listed here is drift waiting
# to happen: add it here, never hand-edit it.
